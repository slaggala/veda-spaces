# Customer Quotation Experience: customer-support runbook

For staff answering a customer about their proposal link. Workspace → property → Scope and quotation → Customer proposal.

| The customer says | What it means | What to do |
|---|---|---|
| "The link says it is not valid" | The link was mistyped or cut off (it is long: copy it whole), or never existed | Create a new link (or **New link** on the existing one) and send it again |
| "The link is no longer active" | It was revoked, or replaced by **New link** | Send the current link; if none is live, create one |
| "The link has expired" | The link passed its own expiry (1–30 days) | Create a new link; the quotation itself may still be valid |
| "A newer version has been shared" | A newer version was shared to the same recipient kind | Make sure they use the newest link |
| "It says past its validity" | The quotation version expired | Issue a revised version (B4) and share it |
| "The proposal cannot be shown" | The frozen document failed its integrity check | **Do not reissue blindly.** Treat as an incident: report the quotation number; nothing is shown until it is resolved |
| "I chose an option but the total did not change" | Live totals are not enabled (CQX-D02): the page says price confirmation required | Confirm the price yourself; a revised version can include it |
| "I asked for a change" | A change request; it changes nothing until staff act | Review it; revise scope/price through B2-B4; link the new version to the request; share it |
| "I can't accept" | Digital acceptance needs owner decisions not yet recorded, required sections not acknowledged, or optional choices without a shown price | The page says why where the customer can act; otherwise record acceptance as today (B4 staff-recorded) |
| "Someone else has my link" | Anyone with the link can open the proposal | Revoke the link and send a new one to the right person |
| "Please delete my data" | Lead erasure | Use the lead erasure process: it revokes every link and erases their messages |

Never ask a customer for their link's text over chat if avoidable; never paste a link into a ticket or note (it opens
the proposal). Staff see links only once, when created.
