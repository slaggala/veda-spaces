# Observation sheet: Estimator V2 homeowner session

One sheet per session, filled in live by the note-taker. Use participant codes only (never names or contact details).
Afterwards, copy each observation into a row of [observations-template.csv](observations-template.csv).

**Scoring:**
- **Outcome:** U = unaided, A = assisted, F = failed.
- **Score:** 2 = correct unaided, 1 = after re-finding it or partly correct, 0 = wrong or a misconception (write it verbatim).
- **SEQ:** "How easy was that?", 1 (very hard) to 7 (very easy).
- **Severity:** Critical, High, Medium or Low (plan §9). Propose one here; it is finalised at synthesis.
